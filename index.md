Assignment 7.5 — Flexbox Mini-Project

Aim

To develop a complete responsive landing page using HTML and CSS Flexbox, including a navigation bar, hero section, three feature cards, a call-to-action section, and a footer.

Flexbox Properties Used

- "display: flex" — Creates flexible layouts.
- "justify-content" — Aligns and distributes items along the main axis.
- "align-items" — Aligns items along the cross axis.
- "flex-wrap: wrap" — Allows elements to move onto another line when space is limited.
- "flex-direction: column" — Stacks elements vertically on smaller screens.
- "gap" — Adds consistent spacing between elements.
- "flex: 1 1 230px" — Allows feature cards to grow and shrink from an initial basis of 230 pixels.

Features

- Responsive navigation bar with logo and links.
- Hero section with heading, description, buttons, and image.
- Three feature cards arranged using Flexbox.
- Call-to-action section with a button.
- Footer with branding and a Back to Top link.
- Consistent colors, typography, spacing, and hover effects.
- Media queries for tablet and mobile screens.
- Layout adjustments to prevent horizontal overflow on smaller screens.

Files Included

- "index.html" — HTML structure of the landing page.
- "style.css" — Styling, Flexbox layouts, and responsive media queries.
